# 📊 Super Store Sales Data Analysis – Excel Project

## 📌 Project Overview
This project analyzes Super Store sales data using Microsoft Excel. The objective is to understand sales performance across regions, employees, products, and categories.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
- Data Analysis

## 📂 Dataset
The dataset contains 50 sales records with the following fields:
- Order ID
- Employee
- Region
- Product
- Category
- Sales
- Quantity
- Order Date
- Target

## 📊 Analysis Performed
- Region-wise Sales Analysis
- Employee-wise Sales Analysis
- Category-wise Sales Analysis
- Product-wise Quantity Analysis
- Pivot Table Analysis
- Sales Visualization

## 📈 Charts
- Sales by Region
- Sales by Employee
- Sales by Category
- Quantity Sold by Product

## 💡 Project Objective
To practice Excel data analysis skills and extract meaningful business insights from sales data.
